## 部分项目

- [ItoCanvas](https://github.com/zhuhroscar-tech/ItoCanvas) — 离线 macOS 期权分析应用，支持 Black–Scholes–Merton 定价、Greeks、隐含波动率、策略和情景分析。
- [DualTyper](https://github.com/zhuhroscar-tech/dualTyper) — 基于 Apple 端侧 Translation framework 的菜单栏工具，用于翻译选中的文字。
- [privaudit](https://github.com/zhuhroscar-tech/privaudit) — 利用 PipeWire 在本地记录 Linux 麦克风和摄像头访问历史。
- [reboot-safety-check](https://github.com/zhuhroscar-tech/reboot-safety-check) — 在重启进入新内核前检查 DKMS 模块风险。
- [trim-doctor](https://github.com/zhuhroscar-tech/trim-doctor) — 检查 SSD 的 TRIM/discard 是否能通过设备、加密和存储层。
- [unmount-doctor](https://github.com/zhuhroscar-tech/unmount-doctor) — 解释哪些进程正在占用 Linux 挂载点。
- [zram-doctor](https://github.com/zhuhroscar-tech/zram-doctor) — 对比 zram 配置与实际运行的设备。
- [usbsmart-doctor](https://github.com/zhuhroscar-tech/usbsmart-doctor) — 帮助选择 USB bridge 对应的 `smartctl` 设备类型，并查看硬盘健康信息。

## 开发习惯

在条件允许时优先使用本地处理，为数值计算和容易出错的逻辑编写测试，并在文档中明确说明限制。各项目的 README 分别介绍安装方法和安全边界。
